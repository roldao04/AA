### Phase Five: Space-Saving Algorithm Implementation

Implement the Space-Saving algorithm which is more sophisticated than the previous two methods due to its dynamic data structure and error tracking capabilities. Create a SpaceSaving class that takes a parameter k specifying how many items to monitor. Initialize the class with an empty dictionary that will store monitored items as keys mapping to tuples of count and error for each item.

Implement the core process method that handles incoming temperature values according to the Space-Saving logic. When a temperature arrives, first check if it's already being monitored—if so, retrieve its current count and error, increment the count by one, and store the updated values back. If the temperature is not currently monitored, check whether you're already monitoring k items. If you're monitoring fewer than k items, simply add the new temperature with count one and error zero since there's no uncertainty yet.

The interesting case occurs when you're already monitoring k items and a new unmonitored temperature arrives. You need to find the item currently being monitored that has the minimum count. Remove this minimum item from your monitored set and replace it with the new temperature. The new temperature's count is set to the minimum count plus one, and crucially, its error is set to the minimum count. This error tracking is what gives Space-Saving its theoretical guarantees—it explicitly acknowledges that the new item might have appeared during the period when it wasn't being monitored, and bounds how much we might be overestimating its true frequency.

Implement helper methods that make querying your Space-Saving results convenient. Create a get_top_k method that returns the k most frequent items according to their current counts, sorted from highest to lowest. Implement a get_monitored_items method that returns all currently monitored items with their counts and error bounds. Create a get_estimated_count method that returns the estimated count for any temperature, returning zero with high error if it's not being monitored.

Implement analysis functions that evaluate Space-Saving's performance rigorously.

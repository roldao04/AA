# SLIDE 06: Introduction to Randomized Algorithms I

## 6.1 Randomized Algorithms - Introduction

### What are Randomized Algorithms?

**Definition**: Algorithms that use a degree of **randomness** as part of their logic.

**Key characteristics**:
- Use random bits as auxiliary input
- Make decisions by "tossing coins"
- Aim for good performance **on average**
- Running time and/or output are **random variables**

### Deterministic vs. Non-Deterministic vs. Randomized

| Type | Behavior | Output | Running Time |
|------|----------|--------|--------------|
| **Deterministic** | Same steps every time | Always same | Always same |
| **Non-Deterministic** | May vary | May vary | May vary |
| **Randomized** | Uses random choices | Probabilistic | Probabilistic |

---

## 6.2 Application Example: Database Comparison

### Problem:
Two computers C1 and C2 at different locations, each with a database:
- DB1 on C1 (n bits)
- DB2 on C2 (n bits)
- Both started identical but evolved independently
- **Question**: Are DB1 and DB2 still identical?

### Deterministic Approach ❌

**Solution**: Send entire database
- **Communication**: At least **n bits**
- **For n = 10¹⁶ bits**: Must send entire 10¹⁶ bits!
- **Problem**: Too expensive for large databases

### Randomized Approach ⭐

**Algorithm**:
```python
# On Computer C1:
def compare_databases_C1(X, n):
    # X is DB1 content (n bits)
    # Choose random prime p from [2, n²]
    p = random_prime(2, n**2)

    # Treat X as binary number
    num_X = binary_to_number(X)

    # Compute s = Number(X) mod p
    s = num_X % p

    # Send (s, p) to C2
    return (s, p)

# On Computer C2:
def compare_databases_C2(Y, s, p):
    # Y is DB2 content (n bits)
    # Compute r = Number(Y) mod p
    num_Y = binary_to_number(Y)
    r = num_Y % p

    # Compare
    if s != r:
        return "DIFFERENT"  # Always correct!
    else:
        return "EQUAL"      # Might be wrong!
```

**Message Size**:
- Need to send `(s, p)` where both `s, p < n²`
- Size: **4 × ⌈log₂ n⌉ bits**
- For n = 10¹⁶: Only **256 bits** instead of 10¹⁶ bits!

### Reliability Analysis

**Case 1**: If X = Y
- Number(X) = Number(Y)
- Therefore: Number(X) mod p = Number(Y) mod p
- **Answer is ALWAYS CORRECT** ✓

**Case 2**: If X ≠ Y
- If Number(X) mod p ≠ Number(Y) mod p → **Correct** ✓
- If Number(X) mod p = Number(Y) mod p → **Wrong** ✗
  - This happens when p is a "bad prime"

**Example**:
```
p = 7
X = 01111  →  Number(X) = 15  →  15 mod 7 = 1
Y = 10110  →  Number(Y) = 22  →  22 mod 7 = 1

Answer: "EQUAL" but X ≠ Y  (WRONG!)
```

### Error Probability

**Single test**:
- Error probability: **at most (ln n²)/n**
- For n = 10¹⁶: Error ≈ 0.36892 × 10⁻¹⁴

**Using k = 10 independent primes**:
- Run test 10 times with different random primes
- Error only if **ALL 10** are bad primes
- Error probability: **< 0.4717 × 10⁻¹⁴¹**
- Message size: 10 × 256 = 2560 bits (still tiny!)

**Conclusion**: Nearly certain correctness with tiny communication!

## 6.3 Random Number Generators

### Pseudo-Random Numbers

**Important**: Computers generate **pseudo-random** numbers, not truly random!

**How it works**:
- Generated by recurrence relations
- Deterministic sequence
- Appears random
- Reproducible with same seed

**Famous failure**: Daniel Corriveau's Keno story
- Casino video keno used predictable RNG
- Pattern discovered, exploited
- Lesson: RNG quality matters!

### Python's `random` Module

#### For Integers:
```python
import random

# Random integer in [a, b] inclusive
random.randint(1, 6)  # Dice roll

# Random element from range
random.randrange(0, 100, 2)  # Even number in [0, 100)

# Random choice from sequence
random.choice(['heads', 'tails'])
random.choice([1, 2, 3, 4, 5, 6])  # Dice
```

#### For Real Numbers:
```python
# Uniform distribution in [0, 1)
random.random()

# Uniform distribution in [a, b]
random.uniform(0, 10)

# Gaussian (normal) distribution
random.gauss(mu=0, sigma=1)  # mean=0, std=1
```

#### Reproducibility:
```python
# Set seed for reproducible results
random.seed(42)
print(random.random())  # 0.6394267984578837

random.seed(42)
print(random.random())  # 0.6394267984578837 (same!)
```

### Python's `secrets` Module

**For security/cryptography**:
```python
import secrets

# Cryptographically strong random numbers
secrets.randbelow(100)
secrets.choice(['A', 'B', 'C'])
secrets.token_hex(16)  # Random hex string
```

**⚠️ Important**: Never use `random` module for security! Use `secrets` instead.

## 6.6 Statistical Experiments

### 6.6.1 Coin Experiments

#### Experiment V1: Balanced Coin

**Setup**: Toss fair coin n times, count heads

**Sample space for n=3**:
```
Outcomes: {HHH, HHT, HTH, HTT, THH, THT, TTH, TTT}
Total: 2³ = 8 equally likely outcomes
```

**Probability Distribution (n=3)**:

| # Heads | Outcomes | Count | Probability |
|---------|----------|-------|-------------|
| 0 | TTT | 1 | 1/8 |
| 1 | HTT, THT, TTH | 3 | 3/8 |
| 2 | HHT, HTH, THH | 3 | 3/8 |
| 3 | HHH | 1 | 1/8 |

**Binary Tree Representation** (n=3):
```
                Start
               /     \
            H /       \ T
             /         \
           H/T         H/T
          / | \       / | \
         / HHH \     / THH \
       HHT  |  HTH THT  |  HTT
            |           |
           TTT         (1 head)
      (3 heads)
```

**General Formula** (Binomial Distribution):
```
P(k heads in n tosses) = C(n,k) × (1/2)ⁿ
```

**Implementation**:
```python
import random

def toss_balanced_coin(n):
    """Toss fair coin n times, return # heads"""
    heads = 0
    for _ in range(n):
        if random.random() < 0.5:  # P(heads) = 0.5
            heads += 1
    return heads

# Simulate experiment many times
def simulate_coin_experiment(n, trials=1000):
    results = []
    for _ in range(trials):
        results.append(toss_balanced_coin(n))
    return results

# Run simulation
results = simulate_coin_experiment(n=3, trials=10000)

# Compare to theory
from collections import Counter
counts = Counter(results)
print(f"Empirical: {counts}")
# Should be close to: {0: 1250, 1: 3750, 2: 3750, 3: 1250}
```

#### Experiment V2: Biased Coin

**Setup**: Coin with P(heads) = 0.45, toss n times

**Probability Distribution (n=3)**:

| # Heads | Probability |
|---------|-------------|
| 0 | (0.55)³ = 0.166375 |
| 1 | C(3,1) × 0.45 × 0.55² = 0.408375 |
| 2 | C(3,2) × 0.45² × 0.55 = 0.334125 |
| 3 | (0.45)³ = 0.091125 |

**Implementation**:
```python
def toss_biased_coin(n, p_heads=0.45):

    return heads
```

### 6.6.3 Compound Experiments

#### Die-Coin Experiment

**Setup**:
1. Throw a die
2. Toss a coin that many times
3. Count heads

**Example Outcomes**:
- Die shows 6 → Toss coin 6 times → Could get 0-6 heads
- Die shows 1 → Toss coin 1 time → Could get 0-1 heads

**Probability of 6 heads**:
- Must throw 6 on die: P = 1/6
- Must get 6 heads in 6 tosses: P = (1/2)⁶ = 1/64
- **Total**: P = (1/6) × (1/64) = 1/384

**Probability of 0 heads**:
```
P(0 heads) = P(die=1, 0H) + P(die=2, 0H) + ... + P(die=6, 0H)
           = (1/6)(1/2) + (1/6)(1/4) + (1/6)(1/8) +
             (1/6)(1/16) + (1/6)(1/32) + (1/6)(1/64)
           = (1/6)[1/2 + 1/4 + 1/8 + 1/16 + 1/32 + 1/64]
           = (1/6)(63/64)
           = 21/128
```

**Implementation**:
```python
def die_coin_experiment():
    """Throw die, then toss coin that many times"""
    num_tosses = random.randint(1, 6)
    heads = 0
    for _ in range(num_tosses):
        if random.random() < 0.5:
            heads += 1
    return heads
```

## 6.7 Simple Games

### Game 1: Red vs Green Die

**Rules**:
- Pay €1 to play
- Roll two dice (red and green)
- Win €2 if red > green
- Otherwise lose €1

**Question**: Should you play?

**Analysis**:
```
Total outcomes: 36

Red > Green outcomes:
Red=2: (2,1) = 1
Red=3: (3,1), (3,2) = 2
Red=4: (4,1), (4,2), (4,3) = 3
Red=5: (5,1), (5,2), (5,3), (5,4) = 4
Red=6: (6,1), (6,2), (6,3), (6,4), (6,5) = 5
Total: 1+2+3+4+5 = 15 outcomes

P(win) = 15/36 = 5/12 ≈ 0.417
P(lose) = 21/36 = 7/12 ≈ 0.583
```

**Expected Value**:
```
E[gain] = P(win) × €2 + P(lose) × (-€1)
        = (15/36) × 2 + (21/36) × (-1)
        = 30/36 - 21/36
        = 9/36
        = €0.25
```

**Answer**: YES! Expected gain of €0.25 per game ⭐

**Simulation**:
```python
def play_dice_game():
    """Red > Green wins €2, else lose €1"""
    red = random.randint(1, 6)
    green = random.randint(1, 6)
    if red > green:
        return 2 - 1  # Win €2, paid €1
    else:
        return -1     # Lost €1

# Simulate many games
games = [play_dice_game() for _ in range(10000)]
print(f"Average gain: €{sum(games)/len(games):.2f}")
# Should be close to €0.25
```

# SLIDE 07: Discrete Probability Theory

## 7.1 Probability Fundamentals

### Probability Space

**Definition**: A probability space consists of (Ω, Pr):
- **Ω** (Omega): Sample space - set of all possible outcomes
- **Pr**: Probability function that assigns Pr(ω) to each ω ∈ Ω

### Probability Distribution

**Properties**:
1. `Pr(ω) ≥ 0` for all ω ∈ Ω (non-negative)
2. `∑ Pr(ω) = 1` (total probability = 1)

**Example - Fair Die**:
```
Ω = {1, 2, 3, 4, 5, 6}
Pr(1) = Pr(2) = ... = Pr(6) = 1/6
∑ Pr = 6 × (1/6) = 1 ✓
```

**Example - Pair of Fair Dice**:
```
Ω = {(1,1), (1,2), ..., (6,6)}
|Ω| = 36
Pr((i,j)) = 1/36 for all (i,j)
```

**Example - "Loaded" Die**:
```
Ω = {1, 2, 3, 4, 5, 6}
Pr(1) = 2/7 (ace twice as likely)
Pr(2) = Pr(3) = Pr(4) = Pr(5) = Pr(6) = 1/7
∑ Pr = 2/7 + 5×(1/7) = 7/7 = 1 ✓
```

## 7.2 Events and Probabilities

### Statistical Experiments

**Definition**: Repeatable experiment where outcome cannot be predicted with certainty

**Sample Space S**: Set representing all possible outcomes

**Event E**: Any subset of sample space
- E ⊆ S
- Collection of elementary events

**Examples**:
```
Experiment: Throw a 6-sided die
S = {1, 2, 3, 4, 5, 6}

Event E₁: "Even number"
E₁ = {2, 4, 6}
P(E₁) = 3/6 = 1/2

Event E₂: "Number > 2"
E₂ = {3, 4, 5, 6}
P(E₂) = 4/6 = 2/3

Event E₃: "Even AND > 2"
E₃ = E₁ ∩ E₂ = {4, 6}
P(E₃) = 2/6 = 1/3
```

### Probability Axioms

**Basic Properties**:
1. `0 ≤ P(E) ≤ 1` for any event E
2. `P(S) = 1` (certainty)
3. `P(∅) = 0` (impossibility)

**Union of Disjoint Events**:
- If A ∩ B = ∅: `P(A ∪ B) = P(A) + P(B)`

**Union of Overlapping Events**:
- `P(A ∪ B) = P(A) + P(B) - P(A ∩ B)`

**Example**:
```
Fair die:
A = "Even" = {2, 4, 6}, P(A) = 3/6
B = "Greater than 2" = {3, 4, 5, 6}, P(B) = 4/6
A ∩ B = {4, 6}, P(A ∩ B) = 2/6

P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
         = 3/6 + 4/6 - 2/6
         = 5/6 ✓

Verification: A ∪ B = {2, 3, 4, 5, 6}, so P = 5/6 ✓
```

## 7.3 Uniform Probability Distribution

**Definition**: Each elementary event has the **same** probability

**Formula**:
```
For uniform distribution on S:
P(A) = |A| / |S| = (# favorable outcomes) / (# total outcomes)
```

**Examples**:

### Example 1: Fair Die
```
S = {1, 2, 3, 4, 5, 6}, |S| = 6

A = "Even number" = {2, 4, 6}, |A| = 3
P(A) = 3/6 = 1/2

B = "Number > 2" = {3, 4, 5, 6}, |B| = 4
P(B) = 4/6 = 2/3

C = "Even OR > 2" = {2, 3, 4, 5, 6}, |C| = 5
P(C) = 5/6
```

### Example 2: Three Fair Coins
```
S = {HHH, HHT, HTH, HTT, THH, THT, TTH, TTT}
|S| = 2³ = 8

A = "At least one head"
A = S \ {TTT} = 7 outcomes
P(A) = 7/8

B = "At least two heads"
B = {HHH, HHT, HTH, THH}
|B| = 4
P(B) = 4/8 = 1/2
```

**Binary Representation**:
```
HHH = 111₂ = 7
HHT = 110₂ = 6
HTH = 101₂ = 5
HTT = 100₂ = 4
THH = 011₂ = 3
THT = 010₂ = 2
TTH = 001₂ = 1
TTT = 000₂ = 0

Counting heads = counting 1-bits!
```

**Triangular (Path) Representation**:
```
        Start
       /     \
      H       T
     / \     / \
    H   T   H   T
   / \ / \ / \ / \
  H  T H T H T H  T

Paths to k heads at level n = C(n,k)
```

## 7.4 Binomial Probability Distribution

### Problem: n Fair Coins

**Question**: What is P(exactly k heads in n tosses)?

**Formula**:
```
P(X = k) = C(n, k) × pᵏ × (1-p)ⁿ⁻ᵏ

Where:
- n = number of trials
- k = number of successes
- p = probability of success
- C(n,k) = n!/(k!(n-k)!)
```

**For fair coin** (p = 1/2):
```
P(X = k) = C(n, k) × (1/2)ⁿ
```

### Examples:

**Example 1**: P(6 heads in 15 tosses of fair coin)
```
n = 15, k = 6, p = 0.5

P(X = 6) = C(15, 6) × (0.5)⁶ × (0.5)⁹
         = C(15, 6) × (0.5)¹⁵
         = 5005 × (1/32768)
         = 5005/32768
         ≈ 0.1527 or 15.27%
```

**Example 2**: P(exactly 3 heads in 5 tosses)
```
P(X = 3) = C(5, 3) × (1/2)⁵
         = 10 × (1/32)
         = 10/32
         = 5/16
         ≈ 0.3125 or 31.25%
```

**Example 3**: P(at least 3 heads in 5 tosses)
```
P(X ≥ 3) = P(X=3) + P(X=4) + P(X=5)
         = C(5,3)×(1/2)⁵ + C(5,4)×(1/2)⁵ + C(5,5)×(1/2)⁵
         = (10 + 5 + 1) × (1/32)
         = 16/32
         = 1/2
```

### Biased Coin Example

**Problem**: Coin with P(heads) = 2 × P(tails)

**Solution**:
```
Let P(T) = x
Then P(H) = 2x
Total: x + 2x = 1
Therefore: x = 1/3

So: P(H) = 2/3, P(T) = 1/3
```

**P(6 heads in 15 tosses)**:
```
P(X = 6) = C(15, 6) × (2/3)⁶ × (1/3)⁹
         = 5005 × (64/729) × (1/19683)
         ≈ 0.0223 or 2.23%
```

**Python Implementation**:
```python
from math import comb

def binomial_prob(n, k, p):
    """P(k successes in n trials with prob p)"""
    return comb(n, k) * (p**k) * ((1-p)**(n-k))

# Fair coin: P(6 heads in 15 tosses)
print(binomial_prob(15, 6, 0.5))  # 0.1527

# Biased coin: P(6 heads in 15 tosses)
print(binomial_prob(15, 6, 2/3))  # 0.0223
```

## 7.5 Independent Events

### Definition

**Two events A and B are independent** if:
```
P(A and B) = P(A) × P(B)
```

The occurrence of one does **not affect** the probability of the other.

### Examples:

**Example 1: Two coin tosses**
```
First toss: A = "Heads"
Second toss: B = "Heads"

P(A) = 1/2
P(B) = 1/2
P(A and B) = P(HH) = 1/4 = (1/2) × (1/2) = P(A) × P(B) ✓

Independent!
```

**Example 2: Drawing cards WITH replacement**
```
A = "First card is Ace"
B = "Second card is Ace"

P(A) = 4/52
P(B) = 4/52 (card replaced!)
P(A and B) = (4/52) × (4/52) = 16/2704

Independent!
```

**Example 3: Drawing cards WITHOUT replacement** ✗
```
A = "First card is Ace"
B = "Second card is Ace"

P(A) = 4/52
P(B|A) = 3/51 (one Ace removed!)
P(A and B) = (4/52) × (3/51) = 12/2652 ≠ (4/52) × (4/52)

NOT independent!
```

## 7.6 Conditional Probability

### Definition

**Conditional probability** of A given B:
```
P(A|B) = P(A and B) / P(B),  if P(B) ≠ 0
```

**Interpretation**: Probability of A, knowing that B has occurred

### For Independent Events:
```
If A and B are independent:
P(A|B) = P(A and B) / P(B)
       = P(A) × P(B) / P(B)
       = P(A)

Knowing B doesn't change probability of A!
```

### Bayes' Theorem

**Formula**:
```
P(A|B) = P(B|A) × P(A) / P(B)
```

**Derivation**:
```
P(A and B) = P(A|B) × P(B)  (definition)
P(A and B) = P(B|A) × P(A)  (symmetric)

Therefore: P(A|B) × P(B) = P(B|A) × P(A)
           P(A|B) = P(B|A) × P(A) / P(B)
```

### Examples:

**Example 1: Disease Testing**
```
D = "Has disease"
+ = "Tests positive"

Given:
P(D) = 0.01 (1% have disease)
P(+|D) = 0.99 (99% sensitivity)
P(+|not D) = 0.05 (5% false positive)

Question: P(D|+) = ?

Solution using Bayes:
P(D|+) = P(+|D) × P(D) / P(+)

First find P(+):
P(+) = P(+|D)×P(D) + P(+|not D)×P(not D)
     = 0.99×0.01 + 0.05×0.99
     = 0.0099 + 0.0495
     = 0.0594

Therefore:
P(D|+) = 0.99 × 0.01 / 0.0594
       = 0.0099 / 0.0594
       ≈ 0.167 or 16.7%

Only 16.7% of positive tests actually have disease!
```

## 7.8 Expected Value and Variance

### Expected Value (Mean)

**Definition**: The average value of a random variable

**Formula** (discrete):
```
E[X] = μ = ∑ xᵢ × P(X = xᵢ)
```

**Interpretation**: Long-run average if experiment repeated many times

**Example 1**: Fair die
```
X = die value
E[X] = 1×(1/6) + 2×(1/6) + 3×(1/6) + 4×(1/6) + 5×(1/6) + 6×(1/6)
     = (1+2+3+4+5+6) / 6
     = 21/6
     = 3.5
```

**Example 2**: Sum of two fair dice
```
S = sum
E[S] = 2×(1/36) + 3×(2/36) + ... + 12×(1/36)
     = 252/36
     = 7
```

**Shortcut**: E[S] = E[D₁] + E[D₂] = 3.5 + 3.5 = 7

### Variance

**Definition**: Measure of spread around the mean

**Formula**:
```
Var(X) = σ² = E[(X - μ)²]
             = E[X²] - (E[X])²
```

**Standard Deviation**: σ = √Var(X)

**Example**: Fair die
```
E[X] = 3.5 (calculated above)

E[X²] = 1²×(1/6) + 2²×(1/6) + ... + 6²×(1/6)
      = (1+4+9+16+25+36) / 6
      = 91/6

Var(X) = E[X²] - (E[X])²
       = 91/6 - (3.5)²
       = 91/6 - 12.25
       = 15.167 - 12.25
       = 2.917

σ = √2.917 ≈ 1.708
```

**Python Implementation**:
```python
import statistics

# Simulate die rolls
rolls = [random.randint(1, 6) for _ in range(100000)]

print(f"Mean: {statistics.mean(rolls):.2f}")      # ≈ 3.50
print(f"Variance: {statistics.variance(rolls):.2f}")  # ≈ 2.92
print(f"Std Dev: {statistics.stdev(rolls):.2f}")  # ≈ 1.71
```

## 7.9 Sum of Independent Random Variables

### Expected Value of Sum

**Theorem**:
```
If Z = X + Y where X, Y are independent:
E[Z] = E[X + Y] = E[X] + E[Y]
```

**Example**: Sum of two dice
```
E[D₁ + D₂] = E[D₁] + E[D₂]
           = 3.5 + 3.5
           = 7 ✓
```

### Variance of Sum

**Theorem**:
```
If Z = X + Y where X, Y are independent:
Var(Z) = Var(X) + Var(Y)
```

**Note**: Standard deviation does NOT add:
```
σ_Z = √(σ²_X + σ²_Y) ≠ σ_X + σ_Y
```

### Sum of n Independent Identically Distributed Variables

**If** S_n = X₁ + X₂ + ... + X_n where all Xᵢ are i.i.d:
```
E[S_n] = n × E[X]
Var(S_n) = n × Var(X)
σ(S_n) = √n × σ(X)
```

**Example**: Sum of 10 dice
```
E[sum] = 10 × 3.5 = 35
Var(sum) = 10 × 2.917 = 29.17
σ(sum) = √29.17 ≈ 5.40
```

## 7.10 Estimating Mean and Variance from Samples

### Sample Mean

**Formula**:
```
μ̂ = (1/n) × ∑ Xᵢ
```

**Implementation**:
```python
def sample_mean(data):
    return sum(data) / len(data)
```

### Sample Variance

**Formula**:
```
σ̂² = [∑ Xᵢ² - (∑ Xᵢ)²/n] / (n-1)
```

**Why (n-1)?** Bessel's correction - unbiased estimator

**Implementation**:
```python
def sample_variance(data):
    n = len(data)
    sum_x = sum(data)
    sum_x2 = sum(x**2 for x in data)
    return (sum_x2 - sum_x**2/n) / (n-1)
```

### Confidence Interval

**Estimate** μ **as**:
```
μ̂ ± σ̂/√n
```

**Example**: 10 rolls of two dice
```
Rolls: [8, 7, 9, 6, 7, 11, 5, 8, 7, 6]

μ̂ = 74/10 = 7.4
σ̂² ≈ 2.12
σ̂ ≈ 1.46

Estimate: 7.4 ± 1.46/√10
        = 7.4 ± 0.46
        = [6.94, 7.86]
```

```python
def coin_repetition():

# Run simulation
```

### Problem 3: Birthday Paradox ⭐

**Question**: In a group of n people, what is P(at least 2 share birthday)?

**Analysis**:
```
P(no match) = P(all different birthdays)
            = (365/365) × (364/365) × (363/365) × ... × ((365-n+1)/365)
            = 365!/(365ⁿ × (365-n)!)

P(at least one match) = 1 - P(no match)
```

**Famous result**: For n = 23, P(match) > 50%!

**Table**:

| n | P(match) |
|---|----------|
| 10 | 11.7% |
| 20 | 41.1% |
| 23 | **50.7%** ⭐ |
| 30 | 70.6% |
| 50 | 97.0% |
| 70 | 99.9% |

**Python**:
```python
def birthday_paradox(n):
    """P(at least 2 people share birthday)"""
    p_no_match = 1.0
    for i in range(n):
        p_no_match *= (365 - i) / 365
    return 1 - p_no_match

print(f"n=23: {birthday_paradox(23):.3f}")  # 0.507
print(f"n=50: {birthday_paradox(50):.3f}")  # 0.970
```

**Simulation**:
```python
def simulate_birthday(n):
    """Simulate n people, check for match"""
    birthdays = [random.randint(1, 365) for _ in range(n)]
    return len(birthdays) != len(set(birthdays))

# Run 10000 simulations for n=23
matches = sum(simulate_birthday(23) for _ in range(10000))
print(f"P(match) ≈ {matches/10000:.3f}")  # ≈ 0.507
```

### Problem 5: Coupon Collector ⭐

**Question**: Collect random items from set of n types. How many draws to collect all?

**Expected value**: E[draws] = n × H_n ≈ n × ln(n)

Where H_n = 1 + 1/2 + 1/3 + ... + 1/n (harmonic number)

For n = 200:
```
E[draws] ≈ 200 × ln(200) ≈ 200 × 5.3 ≈ 1060
```

**Intuition**:
- First coupon: 1 draw (all are new)
- Second: 200/199 draws on average
- Third: 200/198 draws on average
- ...
- Last: 200/1 = 200 draws on average

**Total**: 200 × (1/200 + 1/199 + ... + 1/1) = 200 × H_200

**Simulation**:
```python
def coupon_collector(n=200):
    """Collect all n types"""
    collected = set()
    draws = 0
    while len(collected) < n:
        item = random.randint(1, n)
        draws += 1
        collected.add(item)
    return draws

# Run experiments
results = [coupon_collector(200) for _ in range(300)]
print(f"Average draws: {sum(results)/len(results):.2f}")
# Expected: ≈ 1060
```

## 8.1 Monte Carlo Methods

### What are Monte Carlo Methods?

**Definition**: Algorithms that rely on **repeated random sampling** to obtain numerical results.

**Common uses**:
- Approximate numerical solutions
- Problems in physics and mathematics
- Simulation of complex systems

### General Approach:

1. **Define domain** of possible values
2. **Generate random values** inside domain
3. **Process values** deterministically
4. **Compute result** (approximation!)

---

## 8.2 Example: Approximating π

### Method 1: Circle in Square

**Setup**:
- Unit circle (radius = 1) inside square (side = 2)
- Area of circle: A_circle = π × r² = π
- Area of square: A_square = (2r)² = 4
- Ratio: π/4

**Monte Carlo approach**:
1. Generate random points (x, y) in square [-1, 1] × [-1, 1]
2. Count points inside circle: x² + y² ≤ 1
3. Estimate: π ≈ 4 × (points_inside / total_points)

**Implementation**:
```python
def estimate_pi(num_samples=100000):
    """Estimate π using Monte Carlo"""
    inside_circle = 0

    for _ in range(num_samples):
        x = random.uniform(-1, 1)
        y = random.uniform(-1, 1)

        if x**2 + y**2 <= 1:
            inside_circle += 1

    pi_estimate = 4 * inside_circle / num_samples
    return pi_estimate

# Run estimation
for n in [100, 1000, 10000, 100000, 1000000]:
    estimate = estimate_pi(n)
    error = abs(estimate - 3.14159265359)
    print(f"n={n:7d}: π ≈ {estimate:.6f}, error = {error:.6f}")

# Output:
# n=    100: π ≈ 3.120000, error = 0.021593
# n=   1000: π ≈ 3.144000, error = 0.002407
# n=  10000: π ≈ 3.141200, error = 0.000393
# n= 100000: π ≈ 3.141960, error = 0.000367
# n=1000000: π ≈ 3.141363, error = 0.000230
```

## 8.3 Las Vegas Algorithms

### Definition

**Las Vegas algorithms**:
- Use randomness to reduce **expected running time** or **memory usage**
- **Always** give correct result
- **Terminate** in bounded time
- Running time is probabilistic

### Example: Find 'a' in Array

**Setup**: Array of n ≥ 2 elements, half are 'a', half are 'b'

**Algorithm**:
```python
def find_a_las_vegas(arr):
    """Find 'a' - always succeeds"""
    while True:
        idx = random.randint(0, len(arr)-1)
        if arr[idx] == 'a':
            return idx
```

**Analysis**:
- **Success probability** each trial: P = 1/2
- **Expected trials**: E = 1/p = 1/(1/2) = 2
- **Expected time**: O(1) × 2 = O(1) ⭐
- **Always correct**: Yes! ✓

**Worst case**: Could take forever (but P(very long) → 0)

---

## 8.4 Monte Carlo Algorithms

### Definition

**Monte Carlo algorithms**:
- **Fixed running time**
- May produce **incorrect result** with some probability
- Error probability can be controlled

### Example: Find 'a' with Limited Tries

**Algorithm**:
```python
def find_a_monte_carlo(arr, k=10):
    """Find 'a' - might fail"""
    for _ in range(k):
        idx = random.randint(0, len(arr)-1)
        if arr[idx] == 'a':
            return idx
    return None  # Failed!
```

**Analysis**:
- **Running time**: Exactly k trials = O(k) ✓
- **P(success)**: 1 - (1/2)^k
- For k=10: P(success) = 1 - (1/1024) ≈ 99.9%
- **Might fail**: Yes, with P = (1/2)^k

### Las Vegas vs Monte Carlo Comparison

| Feature | Las Vegas | Monte Carlo |
|---------|-----------|-------------|
| **Correctness** | Always correct ✓ | Might be wrong |
| **Running time** | Random | Fixed |
| **Termination** | Always (bounded) | Always |
| **Error control** | None needed | Via repetitions |
| **Example** | Randomized Quicksort | Fermat primality test |

## 8.5 Random Sampling

### Problem Statement

**Goal**: Choose random sample of size K from population of size N

**Requirements**:
- Every subset of size K must be equally likely
- Unbiased selection

**Total possible samples**: C(N, K) = N!/(K!(N-K)!)

### Algorithm 1: Boolean Array

```python
def random_sample_v1(N, K):
    """Select K items from [1..N] using boolean array"""
    in_sample = [False] * (N + 1)
    count = 0

    while count < K:
        r = random.randint(1, N)
        if not in_sample[r]:
            in_sample[r] = True
            count += 1

    # Extract selected indices
    sample = [i for i in range(1, N+1) if in_sample[i]]
    return sample
```

**Pros**:
- Simple
- Unbiased

**Cons**:
- Requires O(N) space for boolean array
- Slow when K << N (many collisions)

### Algorithm 2: Sorted Integer Array

```python
def random_sample_v2(N, K):
    """Select K items using sorted array (space O(K))"""
    sample = []

    while len(sample) < K:
        r = random.randint(1, N)

        # Binary search to check if r already in sample
        if r not in sample:  # Could use bisect for O(log K)
            sample.append(r)
            sample.sort()

    return sample
```

**Improvement**:
- Space: O(K) instead of O(N) ⭐
- Still unbiased

### Algorithm 3: Reservoir Sampling ⭐

**Problem**: What if N is **unknown** or **too large** to fit in memory?

**Solution**: Jeffrey Vitter's Algorithm R (1985)

**Algorithm**:
```python
def reservoir_sampling(stream, K):
    """
    Sample K items from stream of unknown size.

    stream: iterator of items
    K: sample size
    """
    reservoir = []

    # Phase 1: Fill reservoir with first K items
    for i, item in enumerate(stream):
        if i < K:
            reservoir.append(item)
        else:
            # Phase 2: Randomly replace items
            j = random.randint(0, i)
            if j < K:
                reservoir[j] = item

    return reservoir
```

**Why it works**:
- Each item has probability K/N of being in final sample
- Works even when N is unknown!
- Space: O(K)
- Time: O(N) single pass

**Proof sketch** (item at position m):
```
P(item m in reservoir after n items) = K/n

Base case (m ≤ K): P = 1 (always in reservoir)

For m > K:
P(item m selected) = K/m
P(not replaced in steps m+1..n) = ∏(1 - 1/i) for i=m+1..n
                                 = ∏((i-1)/i) = m/n

Total: P = (K/m) × (m/n) = K/n ✓
```

**Example**:
```python
# Simulate reading from large file
def data_stream():
    """Simulate stream of 1 million items"""
    for i in range(1, 1000001):
        yield i

sample = reservoir_sampling(data_stream(), K=100)
print(f"Sample size: {len(sample)}")  # 100
print(f"Sample range: {min(sample)} to {max(sample)}")
```

## 8.7 Primality Testing

### The Problem

**Input**: Positive integer p
**Question**: Is p prime?
**Applications**: Cryptography (RSA), security

### Naïve Deterministic Approach

**Algorithm**:
```python
def is_prime_naive(p):
    """Check if p is prime (slow!)"""
    if p < 2:
        return False
    if p == 2:
        return True
    if p % 2 == 0:
        return False

    # Check odd divisors up to √p
    for i in range(3, int(p**0.5) + 1, 2):
        if p % i == 0:
            return False
    return True
```

**Complexity**: O(√p)
- For p = 10²⁰: Need to check ≈ 10¹⁰ divisors
- Too slow for large primes!

**Improvements**:
- Check only up to √p ✓
- Skip even divisors ✓
- Still too slow for cryptographic sizes

---

### Fermat's Little Theorem

**Theorem**: If p is prime, then for any integer a where 1 < a < p:
```
aᵖ⁻¹ ≡ 1 (mod p)
```

**Contrapositive**: If a^(p-1) mod p ≠ 1, then p is **composite**!

**Example 1**: p = 15, a = 2
```
2¹⁴ mod 15 = 16384 mod 15 = 4 ≠ 1
Therefore: 15 is composite ✓
(Indeed: 15 = 3 × 5)
```

**Example 2**: p = 17 (prime), a = 2
```
2¹⁶ mod 17 = 65536 mod 17 = 1 ✓
Consistent with p being prime
```

---

### Fermat's Primality Test

**Single test**:
```python
def fermat_test(p):
    """
    Single Fermat test for primality.
    Returns:
        False: p is definitely composite
        True: p is probably prime
    """
    if p <= 3:
        return p > 1

    # Choose random a in [2, p-2]
    a = random.randint(2, p - 2)

    # Check if a^(p-1) mod p == 1
    if pow(a, p - 1, p) != 1:
        return False  # Composite! (a is Fermat witness)

    return True  # Probably prime (a is Fermat liar or p is prime)
```

**Terminology**:
- **Fermat witness**: a for which a^(p-1) mod p ≠ 1 (proves p composite)
- **Fermat liar**: a for which a^(p-1) mod p = 1 but p is composite

**Examples**:

**p = 15, a = 2**:
```
2¹⁴ mod 15 = 4 ≠ 1
→ Fermat witness! p is composite ✓
```

**p = 341, a = 3**:
```
341 = 11 × 31 (composite!)
3³⁴⁰ mod 341 ≠ 1
→ Fermat witness! p is composite ✓
```

**p = 341, a = 2**:
```
2³⁴⁰ mod 341 = 1 ⚠️
→ Fermat liar! p is composite but test says "probably prime"
```

---

### Iterated Fermat Test

**Algorithm**: Run test k times with different random values
```python
def is_prime_fermat(p, k=10):
    """
    Iterated Fermat primality test.

    Args:
        p: number to test
        k: number of iterations

    Returns:
        False: definitely composite
        True: probably prime (error prob ≤ 2^(-k))
    """
    if p <= 3:
        return p > 1
    if p % 2 == 0:
        return False

    # Run k independent tests
    for _ in range(k):
        a = random.randint(2, p - 2)
        if pow(a, p - 1, p) != 1:
            return False  # Definitely composite

    return True  # Probably prime
```

**Error Analysis**:

**Theorem**: If p is composite, at most half of the integers a ∈ [2, p-1] are Fermat liars.

**Consequences**:
- 1 test: Error probability ≤ 50%
- 2 tests: Error probability ≤ 25%
- 3 tests: Error probability ≤ 12.5%
- k tests: Error probability ≤ 2^(-k)
- 10 tests: Error probability ≤ 1/1024 ≈ 0.1% ⭐

**Example**:
```python
# Test a known prime
print(is_prime_fermat(17, k=10))  # True

# Test a known composite
print(is_prime_fermat(15, k=10))  # False

# Test a large prime
p = 2**31 - 1  # Mersenne prime: 2147483647
print(is_prime_fermat(p, k=20))  # True
```

---

### Carmichael Numbers ⚠️

**Problem**: Some composite numbers fool Fermat's test!

**Carmichael number**: Odd composite n where:
```
b^(n-1) ≡ 1 (mod n)  for ALL b coprime to n
```

**Examples**: 561, 1105, 1729, 2465, 2821, 6601, ...

**Example: 561**:
```
561 = 3 × 11 × 17 (composite!)

But for ANY a coprime to 561:
a^560 mod 561 = 1

All a are Fermat liars for 561!
```

**Testing 561**:
```python
# Check if 561 is prime
p = 561

# Try many different values of a
for a in [2, 3, 4, 5, 6, 7, 8, 9, 10]:
    result = pow(a, p-1, p)
    print(f"a={a}: {a}^{p-1} mod {p} = {result}")

# Output: ALL return 1! But 561 = 3×11×17 is composite
```

**Solution**: Use better tests (Miller-Rabin, Baillie-PSW)

---

### Better Primality Tests

**Solovay-Strassen (1977)**:
- First Monte Carlo primality test
- Based on Jacobi symbol
- Error probability ≤ 2^(-k)

**Miller-Rabin (1980)** ⭐:
- Most widely used
- Based on stronger properties than Fermat
- Handles Carmichael numbers ✓
- Error probability ≤ 4^(-k)
- Used in practice for cryptography

**Baillie-PSW (1980)**:
- Combination of tests
- No known counterexamples
- Deterministic for practical purposes

**AKS (2002)**:
- First proven polynomial-time deterministic algorithm
- PRIMES is in P!
- O((log n)^12) originally, improved to O((log n)^6)
- **Not used in practice** - Monte Carlo tests faster!

**Practical choice**: Miller-Rabin with k=20 iterations

## 8.8 Randomized Searching

### Randomized Linear Search

**Algorithm**:
```python
def randomized_search(arr, target):
    """
    Search for target in array using random indices.
    Avoids checking same index twice.
    """
    n = len(arr)
    checked = set()

    for _ in range(n):
        # Generate random index not yet checked
        idx = random.randint(0, n-1)
        while idx in checked:
            idx = random.randint(0, n-1)

        checked.add(idx)

        if arr[idx] == target:
            return idx

    return -1  # Not found
```

**When is it better than linear search?**

**Answer**: When array contains **multiple occurrences** of target!

**Example**:
```
Array: [1, 2, 3, 5, 5, 5, 5, 5, 8, 9]
Target: 5

Linear search: Checks indices 0,1,2,3 → 4 comparisons
Random search: Might check index 5 first → 1 comparison!

Average for random: ≈ 2 comparisons (since 5/10 = 50% are target)
```

**Performance comparison**:
```python
def compare_search_performance():
    # Array with many duplicates
    arr = [1]*10 + [5]*50 + [9]*10  # 70% are 5's
    target = 5

    linear_comps = []
    random_comps = []

    for _ in range(1000):
        # Linear search
        comps = 0
        for i, val in enumerate(arr):
            comps += 1
            if val == target:
                break
        linear_comps.append(comps)

        # Random search
        comps = 0
        checked = set()
        while True:
            idx = random.randint(0, len(arr)-1)
            if idx not in checked:
                checked.add(idx)
                comps += 1
                if arr[idx] == target:
                    break
        random_comps.append(comps)

    print(f"Linear: avg {sum(linear_comps)/len(linear_comps):.2f}")
    print(f"Random: avg {sum(random_comps)/len(random_comps):.2f}")

# Output:
# Linear: avg 11.00 (always finds at index 10)
# Random: avg 1.43 (finds quickly due to 70% coverage)
```

## 8.9 Randomized Quicksort

### Standard Quicksort Problem

**Issue**: Worst case O(n²) when array is sorted and we always pick first element as pivot

**Example** (always choose first as pivot):
```
[1, 2, 3, 4, 5]
Pivot = 1: partition into [] and [2,3,4,5]  → unbalanced!
Pivot = 2: partition into [] and [3,4,5]
...
Total: O(n²)
```

### Randomized Quicksort

**Idea**: Choose pivot **randomly** instead of deterministically

**Algorithm**:
```python
def randomized_quicksort(arr):
    """Quicksort with random pivot selection"""
    if len(arr) <= 1:
        return arr

    # Choose random pivot
    pivot_idx = random.randint(0, len(arr) - 1)
    pivot = arr[pivot_idx]

    # Partition
    less = [x for x in arr if x < pivot]
    equal = [x for x in arr if x == pivot]
    greater = [x for x in arr if x > pivot]

    # Recurse
    return (randomized_quicksort(less) +
            equal +
            randomized_quicksort(greater))
```

**Benefits**:
- **Average case**: O(n log n) always! ⭐
- **Worst case**: Still O(n²), but...
- **Probability of worst case**: Extremely low!

**Analysis**:
```
P(worst case) = P(always choose min/max as pivot)
              ≤ 2^n / n!
              ≈ 0 for any reasonable n

For n=100: P(worst case) ≈ 10^(-140) - essentially impossible!
```

**Comparison**:
```python
import time

def measure_quicksort(arr, randomized=False):
    """Measure comparisons in quicksort"""
    comparisons = [0]  # Use list for mutability

    def qsort(arr):
        if len(arr) <= 1:
            return arr

        if randomized:
            pivot_idx = random.randint(0, len(arr)-1)
        else:
            pivot_idx = 0  # Always first

        pivot = arr[pivot_idx]

        less = []
        equal = []
        greater = []

        for x in arr:
            comparisons[0] += 1
            if x < pivot:
                less.append(x)
            elif x == pivot:
                equal.append(x)
            else:
                greater.append(x)

        return qsort(less) + equal + qsort(greater)

    result = qsort(arr)
    return comparisons[0]

# Test on sorted array (worst case for standard)
sorted_arr = list(range(100))

standard = measure_quicksort(sorted_arr, randomized=False)
randomized = measure_quicksort(sorted_arr, randomized=True)

print(f"Standard: {standard} comparisons")   # ≈ 5000 (O(n²))
print(f"Randomized: {randomized} comparisons")  # ≈ 600 (O(n log n))
```

## 8.10 Randomized Algorithms for Optimization

### Approach

**For optimization problems** (minimize/maximize objective function):

1. Run randomized algorithm **k times**
2. Keep **best** solution found
3. Return best solution

**Why it works**: Multiple tries increase chance of finding good solution

### Probability of Success

**If** each run has probability 1/n of finding optimal solution:

**After k runs**:
```
P(no optimal solution) = (1 - 1/n)^k

For k = n:
P(no optimal) = (1 - 1/n)^n → 1/e ≈ 0.368 as n → ∞

Therefore:
P(at least one optimal) ≥ 1 - 1/e ≈ 0.632 or 63.2%
```

**Interpretation**: Running n times gives >63% chance of finding optimal!

---

### Approximation Accuracy

**For minimization problems**:

**Definitions**:
- s*: optimal solution
- s_a: approximate solution
- f(): objective function

**Relative error**:
```
re(s_a) = (f(s_a) - f(s*)) / f(s*)
```

**Accuracy ratio**:
```
r(s_a) = f(s_a) / f(s*)
```

**Performance ratio** R_A:
- Lowest upper bound on all r(s_a)
- Should be close to 1
- R_A = 1 means always optimal

**For maximization problems**: Formulas swap f(s_a) and f(s*)

### Example: Randomized TSP

**Problem**: Traveling Salesman Problem

**Randomized Algorithm**:
```python
import random

def random_tsp_tour(distances):
    """Generate random tour for TSP"""
    n = len(distances)
    cities = list(range(n))

    # Random permutation
    random.shuffle(cities)

    # Add return to start
    tour = cities + [cities[0]]

    # Calculate cost
    cost = sum(distances[tour[i]][tour[i+1]]
               for i in range(n))

    return tour, cost

def randomized_tsp(distances, iterations=1000):
    """
    Approximate TSP using random sampling.

    Args:
        distances: n×n distance matrix
        iterations: number of random tours to try

    Returns:
        (best_tour, best_cost)
    """
    best_tour = None
    best_cost = float('inf')

    for _ in range(iterations):
        tour, cost = random_tsp_tour(distances)

        if cost < best_cost:
            best_cost = cost
            best_tour = tour

    return best_tour, best_cost
```

**Performance Analysis**:
```python
# Small example: 4 cities
distances = [
    [0, 10, 15, 20],
    [10, 0, 35, 25],
    [15, 35, 0, 30],
    [20, 25, 30, 0]
]

# Find optimal (exhaustive search)
from itertools import permutations

def exact_tsp(distances):
    """Exact TSP using exhaustive search"""
    n = len(distances)
    cities = list(range(1, n))  # Fix city 0

    best_cost = float('inf')
    best_tour = None

    for perm in permutations(cities):
        tour = [0] + list(perm) + [0]
        cost = sum(distances[tour[i]][tour[i+1]]
                  for i in range(n))

        if cost < best_cost:
            best_cost = cost
            best_tour = tour

    return best_tour, best_cost

# Compare
optimal_tour, optimal_cost = exact_tsp(distances)
print(f"Optimal: {optimal_tour}, cost = {optimal_cost}")

for k in [10, 100, 1000, 10000]:
    approx_tour, approx_cost = randomized_tsp(distances, k)
    ratio = approx_cost / optimal_cost
    print(f"k={k:5d}: cost = {approx_cost}, ratio = {ratio:.3f}")

# Output:
# Optimal: [0, 1, 3, 2, 0], cost = 80
# k=   10: cost = 95, ratio = 1.188
# k=  100: cost = 85, ratio = 1.063
# k= 1000: cost = 80, ratio = 1.000 ⭐
# k=10000: cost = 80, ratio = 1.000
```

## Key Probability Formulas

### Basic Probabilities:
```
P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
P(A and B) = P(A) × P(B)  [if independent]
P(A|B) = P(A and B) / P(B)
```

### Binomial Distribution:
```
P(k successes in n trials) = C(n,k) × p^k × (1-p)^(n-k)
```

### Random Variables:
```
E[X] = ∑ xᵢ × P(X = xᵢ)
Var(X) = E[X²] - (E[X])²
σ = √Var(X)

E[X + Y] = E[X] + E[Y]
Var(X + Y) = Var(X) + Var(Y)  [if independent]
```

```python
def estimate_pi_with_confidence(samples=100000):
    """Estimate π with confidence interval"""
    inside = 0

    for _ in range(samples):
        x = random.uniform(-1, 1)
        y = random.uniform(-1, 1)
        if x**2 + y**2 <= 1:
            inside += 1

    # Point estimate
    p_hat = inside / samples
    pi_estimate = 4 * p_hat

    # Standard error
    se = (p_hat * (1 - p_hat) / samples) ** 0.5

    # 95% CI: ± 1.96 × SE
    margin = 1.96 * 4 * se

    print(f"π ≈ {pi_estimate:.6f} ± {margin:.6f}")
    print(f"95% CI: [{pi_estimate-margin:.6f}, {pi_estimate+margin:.6f}]")
    print(f"Actual π: 3.141593")

estimate_pi_with_confidence(100000)
```
